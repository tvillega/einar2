Release notes RC1

Glossary

dom0 is the physical machine, domU is a virtual machine.

Limitations

Links

It is only possible to have 3 interfaces on a router, this is why we have modified the lab KTH-LAN. The reason for this is a bug in Xen.

Known bugs

IS-IS does not work

"Warning: Closing connection to isisd because of I/O error!". This is probably a bug in Quagga

Lab CCNP 6.10.1 is missconfigured

This will be a good troubleshooting execise. Locate the missconfiguration and edit /var/www/cgi-bin/labs/CCNP/6.10.1/startlab.sh to fix it. Run xm destroy Workstation2 after stopping the lab

Monitor is not detected

The monitor is not detected in 2.6.15 kernel.

Computer is not automatically shut down

Shutdown locks the CD in the drive. Hit reset

More in domU shows only first page

This bug is inherited from Crab.

Unsupported harware

Xfce doesn't want to start on Nvidia TNT2, this can be mitigated by appending the kernel parameter xmodule=nv
